## Реализовано

- Добавлена история заказов покупателя по адресу `/orders`.
- Добавлена история заказов сотрудника по адресу `/staff/orders`.
- Покупатель видит только свои заказы.
- Сотрудник видит только заказы своего заведения.
- История покупателя разделена на «Актуальные» и «Завершённые».
- В актуальном оплаченном заказе показываются шестизначный код получения и ссылка на существующую страницу с QR.
- В истории показываются дата заказа, набор, заведение, окно выдачи, сумма, статус и состояние возврата.
- Оплаченный заказ считается актуальным только до `pickup_end`.
- Если покупатель не пришёл до конца окна выдачи, заказ переносится в «Завершённые» и получает статус «Время получения истекло».
- Поддержано отображение статуса «Получен» для будущего статуса выдачи.
- Временные заглушки `/orders` и `/staff/orders` удалены из `ComingSoonController`.
- Добавлен тестовый код получения `676889` в тестовых данных истории.
