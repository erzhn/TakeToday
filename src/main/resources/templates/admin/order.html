Ручной возврат

Заказ ещё не выдан: он будет отменён, код получения перестанет действовать, деньги вернутся покупателю.

Вернуть деньги по успешным платежам, по которым возврата ещё не было или он не удался.

Возврат ждёт ответа платёжной службы — система повторяет его сама, можно повторить сейчас.

Возвращать нечего: успешных платежей без возврата нет.
